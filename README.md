# 📊 Superstore Sales Dashboard

An interactive Sales Analysis Dashboard built using Python, Pandas, Plotly, and Streamlit to analyze sales performance and business insights.

## 📌 Project Overview

This project focuses on analyzing Superstore sales data and presenting meaningful business insights through an interactive dashboard.

The dashboard helps users understand sales, profit, order performance, and monthly sales trends using interactive visualizations and filters.

## 🎯 Project Objectives

- Analyze Superstore sales data.
- Perform data cleaning and exploratory data analysis (EDA).
- Identify sales and profit trends.
- Visualize business performance.
- Build an interactive dashboard using Streamlit.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Plotly
- Streamlit

## 📂 Dataset

- Dataset: Sample - Superstore.csv
- Format: CSV
- Contains sales, profit, order, product, category, region, and customer-related information.

## ⚙️ Project Workflow

1. Dataset Collection
2. Data Cleaning
3. Exploratory Data Analysis (EDA)
4. Duplicate and Missing Value Checking
5. Data Visualization
6. Dashboard Development
7. Interactive Filtering
8. Dashboard Deployment

## 📊 Dashboard Features

### 1. KPI Cards
- Total Sales
- Total Profit
- Total Orders

### 2. Interactive Filters
- Category Filter
- Region Filter
- Segment Filter

### 3. Interactive Charts
- Sales by Category
- Profit by Region
- Monthly Sales Trend

### 4. Sales Data Table
Displays sales records for data exploration.

## 💻 How to Run Locally

Clone the repository:

```bash
git clone https://github.com/anoopipal/Superstore-Sales-Dashboard.git
```

Navigate to the project folder:

```bash
cd Superstore-Sales-Dashboard
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the Streamlit application:

```bash
streamlit run app.py
```
